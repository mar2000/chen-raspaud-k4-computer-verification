# Public release checklist

Before citing this package in the manuscript:

- [ ] Create a public repository (suggested short name: `chen-raspaud-k4`).
- [ ] Upload the contents of this directory, not the historical exploratory archive.
- [ ] Create a tagged release, e.g. `v1.0.0`.
- [ ] Preferably archive that release in Zenodo and obtain a DOI.
- [ ] Replace the placeholders in `BIBTEX_ENTRY.txt`.
- [ ] If desired, add the repository/archive URL to `CITATION.cff`.
- [ ] Run `./run_all_checks.sh` from a clean clone before publishing the release.
- [ ] Cite the immutable DOI/release in the paper rather than the moving default branch.
